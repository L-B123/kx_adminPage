# DSSAST CMS 管理员使用与测试手册

适用 DSSAST CMS 0.4.5。供笃实书院学生科协网站管理员、内容审核人员和测试同学使用。

界面文字以实际 WordPress 中文后台为准。版本验收见[本地验收](TESTING.md)。

## 1. 先了解这个管理后台

DSSAST CMS 安装在 WordPress 内。管理员登录测试站点的 `/wp-admin/` 后，从以下入口工作。

| 入口 | 用途 | 谁来操作 |
| --- | --- | --- |
| 插件 → 已安装插件 | 启用、停用 DSSAST CMS | 管理员 |
| 内容管理 | 从赛事管理、学习笔记、新闻管理和公告管理四个卡片进入对应栏目。顶部数量直达待审笔记和已发布赛事 | 管理员 |
| 赛事管理 | 查看赛事列表、添加赛事、维护赛事分类 | 管理员 |
| 学习笔记 | 查看学生投稿、填写意见、退回、发布 | 管理员 |
| 新闻管理 | 查看和添加新闻，进入秀米同步 | 管理员 |
| 公告管理 | 查看和添加公告 | 管理员 |
| 文章 | 发布新闻、公告；审核秀米导入草稿 | 按 WordPress 原生文章权限 |
| 页面 | 创建赛事展示页和笔记投稿页 | 有页面编辑权限的人员 |
| 媒体 | 管理封面和秀米上传图片 | 按原生媒体权限 |
| 新闻管理 → 秀米同步 | 查看接口地址、发起绑定、查看最近错误。也可从“工具 → 秀米同步”进入 | 管理员 |

赛事和学习笔记使用经典编辑器，由管理员维护。学生从网站前台投稿页面提交笔记和查阅审核意见。秀米密钥在服务器上配置。

## 2. 安装与首次准备

### 2.1 安装插件

1. 准备本地 WordPress，确认可以登录后台。插件本身不包含 WordPress、数据库或服务器。
2. 进入“插件 → 安装插件 → 上传插件”。
3. 选择 DSSAST CMS 的插件 ZIP 包，点击“现在安装”，安装完成后启用。
4. 确认左侧出现“内容管理”“赛事管理”“学习笔记”“新闻管理”和“公告管理”，并可从“新闻管理”进入“秀米同步”。
5. 在“文章 → 分类”检查“新闻”“公告”分类。升级旧版本后可停用再启用一次，补建分类并刷新路由。

也可以将 `dssast-cms` 文件夹复制到测试站点的 `wp-content/plugins/` 后启用。不要把整个开发工作区或 `.local-test` 文件夹上传为插件。

声明最低环境为 WordPress 6.6、PHP 7.4；目前实际测试环境为 WordPress 7.1.4、PHP 8.3.36 和 SQLite。最低版本兼容性尚未验证。秀米图片处理还需要 GD 或 Imagick。

### 2.2 准备测试账号和时区

1. 保留一个管理员测试账号。
2. 通过“用户 → 添加用户”建立两个普通测试账号，角色使用“订阅者”。不要为投稿而分配管理员权限。
3. 在“设置 → 常规”确认时区。赛事报名时间按站点时区解释；之后修改时区不会自动转换旧数据。
4. 管理员使用一个浏览器窗口，学生账号使用另一浏览器或无痕窗口，避免混淆身份。

### 2.3 建立两个测试页面

进入“页面 → 新建页面”，分别建立以下页面。点击添加区块，搜索并选择“短代码”，不要使用“代码”区块。

| 页面标题示例 | 短代码区块内容 | 发布后的用途 |
| --- | --- | --- |
| 赛事一览 | `[dssast_competitions limit="5"]` | 独立验证赛事展示 |
| 笔记投稿 | `[dssast_note_submit]` | 学生提交笔记、查看本人投稿 |

发布后通过“查看页面”访问前台，保存页面地址供测试账号使用。是否出现在网站导航中由主题导航配置决定，创建页面不会保证自动出现在首页。投稿页面应从整页缓存和 CDN 缓存中排除。

## 3. 赛事管理

### 3.1 新建并发布赛事

1. 进入“赛事管理”，选择“添加赛事”。
2. 输入赛事标题，在正文区添加介绍、赛制、参赛要求等内容。
3. 在编辑器设置中选择赛事分类，设置特色图片作为封面；需要时填写摘要。
4. 找到“赛事信息”面板，填写下表字段。面板可能位于正文编辑区下方，必要时向下滚动。
5. 先保存草稿，重新打开检查字段，再预览正文。
6. 确认无误后发布，访问“赛事一览”测试页检查展示。

| 字段 | 如何填写 | 示例及规则 |
| --- | --- | --- |
| 赛事状态 | 从下拉框选择 | 筹备中、报名中、报名结束、已结束、已取消；可未设置 |
| 赛事日期 | 选择单日日期 | 2026-12-20；不支持日期范围 |
| 报名开始 | 选择日期和时间 | 2026-12-01 09:00，按站点时区 |
| 报名截止 | 选择日期和时间 | 2026-12-15 18:00，不得早于报名开始 |
| 报名链接 | 填写完整链接 | 使用实际报名表的 `https://…` 地址，支持 HTTP(S) |

所有业务字段允许留空。可用 `https://example.com/` 做测试占位链接，但它不是实际报名入口。

**注意两个不同的状态：**WordPress 的草稿/发布决定文章是否公开；“赛事状态”只是赛事进度标签。选择“报名中”不会自动发布赛事，也不会自动开启报名表。时间到期后状态不会自动改变，需管理员手动更新。

### 3.2 更新与保存失败

打开已有赛事，修改字段后点击编辑器的更新或保存按钮，再刷新页面核对。清空字段并保存会删除该字段值。

若出现“赛事业务字段未保存”，检查日期、开始/截止顺序和链接格式。此时整组业务字段保留原值，但标题、正文可能已经保存成功；不要以标题更新成功推断所有字段都保存了。

业务字段不随核心修订恢复，也不参与自动保存。离开编辑页前应主动保存并核对。

### 3.3 在赛事列表中快速编辑

在赛事标题下打开“快速编辑”，找到“赛事信息”。可以直接调整赛事状态、赛事日期、报名起止时间和报名链接。点击“更新”后，列表会刷新赛事状态和日期。WordPress 自带的“日期”字段表示文章发布时间。需要修改赛事介绍时，打开完整编辑页。

如果报名时间顺序或链接格式不合法，快速编辑面板会提示错误并保留已有赛事内容。修正后可在原面板重新保存。

### 3.4 前台报名入口

测试短代码按最新发布时间列出公开赛事，展示标题、封面、简介、状态、日期、报名时间和链接；不会列出草稿、私密和密码保护赛事。默认 5 条，数量限制为 1–50。分类用于后台组织，当前最小短代码不显示分类标签。

点击赛事标题会进入赛事单页。主题渲染 WordPress 正文时，插件会在正文下附加赛事信息。报名链接留空时，插件省略报名入口。

学生通过“报名链接”或“前往报名”进入管理员配置的表单，表单负责收集报名、限制访问和管理名单。报名开始、截止以及赛事状态用于展示。需要停收时，在报名表中关闭提交，并在后台更新赛事状态。

## 4. 学生投稿与管理员审核

### 4.1 学生如何投稿

1. 打开“笔记投稿”前台页面。未登录时页面显示登录提示。
2. 使用普通测试账号登录，返回该页面。
3. 填写标题、正文，点击“提交审核”。标题输入框最多 200 字符，正文还有服务器长度限制；过长时需缩减内容。
4. 页面返回后查看“我的投稿（最近 30 条）”，确认出现标题及“待审核”。

正文是文本输入框，支持基本安全 HTML，不是完整 Gutenberg 编辑器。脚本、动态区块和可执行短代码不作为投稿功能提供。当前不支持上传附件、图片或设置笔记封面。新投稿每分钟最多一篇；遇到限制应稍后再试，不要连续点击。

### 4.2 管理员审核并发布

1. 管理员进入“学习笔记”，查找待审核稿件并打开。
2. 检查作者、标题、正文、内容来源及链接；需要时直接修订正文。
3. 找到“笔记审核”面板，确认**没有勾选“退回作者修改”**。
4. 使用编辑器的发布按钮发布。
5. 返回列表确认状态为已发布，并检查公开页面中的正文。

前台可用 `[dssast_notes]` 显示已发布的笔记。管理员可用编辑器的查看链接打开单篇笔记。

### 4.3 退回作者修改

1. 在“笔记审核”面板填写明确的审核意见，例如“请补充实验步骤和参考来源”。
2. 勾选“退回作者修改”，点击编辑器的保存或更新按钮。
3. 返回列表确认稿件变为草稿。
4. 学生打开投稿页面，在“我的投稿”中点击“修改再提交”。
5. 学生在表单上方查看审核意见，修改后再次提交。
6. 管理员重新审核，发布时不要再勾选退回选项。

流程为：**提交 → 待审核 → 退回为草稿 → 修改再提交 → 待审核 → 发布**。学生不能修改他人的笔记，也不能改写自己待审核或已发布的笔记。已发布稿件如需作者修改，管理员退回会使其取消公开，应确认这是预期操作。

本版本没有邮件或站内通知功能，管理员与学生应主动检查列表。审核意见目前不会在再次提交时自动清空，管理员可在下一轮审核中更新。

## 5. 新闻与公告

1. 进入原生“文章 → 新建文章”。
2. 输入标题与正文，设置特色图片和摘要。
3. 在分类中选择“新闻”或“公告”。
4. 预览后发布，使用文章查看链接检查。

插件默认使用 `dssast-news`、`dssast-announcement` 分类。正式站沿用 `news`、`announcements` 分类。分类别名用于归档地址和后台栏目查询。新闻公告使用 WordPress 原生的文章发布权限。

## 6. 秀米同步管理

### 6.1 管理页面有哪些内容

“新闻管理 → 秀米同步”包含：

- 配置方式说明：密钥在服务器环境变量或 `wp-config.php` 中配置，页面不显示密钥。
- 三个接口地址：html 接收图文、image 接收图片、notify 接收通知。以后台实际显示地址为准。
- “绑定当前管理员的秀米账号”按钮。
- “最近错误（最多100条）”列表，显示时间和错误类型。记录时间为 UTC；换算为北京时间时加 8 小时。

界面目前没有完整的绑定状态仪表盘、配置输入表单、成功同步历史或日志清空按钮。没有错误记录不等于已完成绑定或同步成功，应以实际草稿和媒体记录验证。

### 6.2 首次配置与同步

1. 请技术同学在服务器配置 `DSSAST_XIUMI_APP_ID` 和 `DSSAST_XIUMI_SECRET`，并确认图片处理扩展可用。不要将密钥发到公开群、截图或代码仓库。
2. 管理员在秀米应用后台填写本插件显示的三个接口地址。
3. 回到 WordPress，点击绑定按钮，登录预期的秀米账号并完成绑定。
4. 绑定通知被本站接收后，在秀米准备一篇测试图文，执行同步。
5. 在 WordPress“文章 → 草稿”检查导入文章，在“媒体”检查图片。
6. 审核排版、封面和内容，选择新闻或公告分类，再手动发布。

秀米服务器无法直接调用你电脑上的 `localhost` 或 `127.0.0.1`。本地模拟接口测试与真实秀米联调是两个阶段；真实联调需另行准备秀米可访问的测试服务地址，不要直接改动官网。具体配置见 [XIUMI.md](XIUMI.md)。

### 6.3 同步规则与限制

| 情况 | 插件行为 |
| --- | --- |
| 首次同步图文 | 保存为原生文章草稿，不自动发布 |
| 相同来源文章、相同内容再次同步 | 跳过重复写入 |
| 同一来源文章内容变化，本站仍为草稿 | 更新草稿；本站人工编辑的正文可能被覆盖 |
| 本站文章已发布或不是草稿，来源内容变化 | 拒绝覆盖，返回冲突错误 |
| 相同用户重复上传同一图片内容 | 复用已有媒体 URL |
| 密钥重置通知成功接收 | 旧密钥停用，需技术同学配置新密钥 |

秀米图片只接受 JPEG、PNG、GIF、WebP，单张不超过 5 MiB、总像素不超过 2000 万。图片重新编码，动画可能失去动画效果；SVG 和部分复杂排版不保留。上传媒体具有公开 URL，不用于私密素材。

## 8. 已有测试记录与技术复测

根据仓库现有测试记录，本地 WordPress 7.1.4 / PHP 8.3.36 / SQLite 环境已通过 PHP 语法检查，以及 20 项集成断言、5 项真实 HTTP 图片接口检查、3 项 HTTP 登录投稿检查。本手册编写过程中没有重新执行这些功能测试。

尚未完成：Gutenberg 浏览器完整交互、真实秀米账号和公网回调联调、MySQL/MariaDB、其他版本兼容性及压力测试。主题前台完整集成也不属于现有最小短代码的验收结果。

技术同学可在**可丢弃的本地 WordPress 数据库**中复跑集成脚本。需启用插件，环境类型为 local，用户 ID 1 为测试管理员。在插件目录执行：

```text
php tests/integration.php /absolute/path/to/wordpress/wp-load.php
```

Windows 请将最后一个参数替换为实际 `wp-load.php` 的绝对路径。脚本会修改测试管理员的秀米绑定数据，并创建或删除测试用户、文章，因此不可在正式站点或需要保留的业务数据库上直接运行。完整技术清单见 [TESTING.md](TESTING.md)。

## 9. 常见问题

| 现象 | 排查与处理 |
| --- | --- |
| 没看到赛事或学习笔记菜单 | 确认插件已启用，并使用管理员账号；普通编辑角色没有模块管理权限 |
| 页面直接显示短代码文字 | 确认使用“短代码”区块、拼写正确且插件启用 |
| 赛事列表为空 | 确认至少有一篇公开发布且无密码保护的赛事 |
| 赛事正文更新了，时间没有变化 | 查看保存错误提示，修正格式及起止顺序后重新保存 |
| 单页看不到报名字段 | 确认相关字段已填写并保存，再用赛事短代码列表交叉检查。只有单页缺失时请前端负责人确认主题正文渲染。 |
| 投稿后不能编辑 | 待审核及已发布笔记不允许作者修改；需管理员退回 |
| 提示每分钟最多提交一篇 | 等待一分钟后再新建投稿，不要反复点击 |
| 提示验证失败或页面过期 | 先复制未保存内容，刷新并重新登录后重试；技术同学检查投稿页缓存 |
| 发布笔记后仍是草稿 | 检查是否同时勾选了“退回作者修改”，取消后重新发布 |
| 新闻/公告分类缺失 | 确认升级后已停用再启用插件，再检查文章分类 |
| 赛事链接 404 | 确认插件启用；由管理员在测试站点检查固定链接设置并保存刷新 |
| 秀米同步提示认证失败 | 技术同学检查密钥一致性、HTTPS 和代理 Authorization 转发 |
| 秀米提示 dssast_binding | 检查是否完成绑定通知、账号仍为管理员及绑定是否解除 |
| 秀米提示 dssast_existing_not_draft | 文章已非草稿，插件拒绝覆盖；由管理员决定内容更新方式 |
| 图片提示 dssast_image_decode | 检查图片是否有效，以及 PHP 的 GD/Imagick 支持 |
| 持续提示 dssast_busy 或重复提交 | 先停止重复请求，请技术同学检查是否有未结束请求或残留锁，不自行删除数据库记录 |

## 10. 停用、升级与交接

停用插件不会删除赛事、笔记、分类、图片和同步数据，但相关管理入口、短代码功能和路由会停止工作。删除插件文件也不会自动清理业务数据。升级前备份数据库和上传目录，升级后按验收表检查；如需彻底清理，单独交由技术同学确认数据范围。

交接给下一任管理员时提供：测试/管理入口、账号分配方式、两个业务页面地址、新闻分类说明、审核约定、技术负责人和密钥存放方式。不要在本手册中填写真实密码或密钥。
