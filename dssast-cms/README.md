# DSSAST CMS 0.3.0

本机启动、登录、账号密码位置和操作验收请先阅读 [本地测试指导](LOCAL-TEST-GUIDE.md)。

0.3.0：新增“内容管理”统一后台入口；赛事与笔记采用经典编辑器，避免依赖区块编辑器资源加载。赛事单页自动展示状态、时间及报名链接。新增 `[dssast_notes]`、`[dssast_news]` 和 `[dssast_news category="dssast-announcement"]` 列表。升级自动补建新闻公告分类，秀米新同步稿自动归入新闻草稿。下文旧版 Gutenberg 操作说明以此为准。秀米真实账号联调仍需配置应用与公网回调。

管理员日常操作与逐步验收请先阅读 [管理员使用与测试手册](ADMIN-GUIDE.md)。

独立 WordPress 插件，提供赛事管理、登录用户笔记投稿审核、新闻公告分类和秀米同步。运行时无第三方依赖，不修改主题或核心。未操作线上网站，未向外部模型发送代码。

## 安装

1. 在本地准备 PHP 7.4+、WordPress 6.6+ 和数据库；以上为声明最低版本，尚未经过兼容性矩阵验证。以本地后台显示的实际版本为准，不将背景中的 7.1.4 视为已验证版本。
2. 将整个 `dssast-cms` 目录复制至 `wp-content/plugins/`，或压缩该目录后通过插件上传安装。
3. 启用 DSSAST CMS，使用管理员账号进入“赛事”。建议用 Twenty Twenty-Five 测试。
4. 添加标题、介绍正文、摘要、特色图片、赛事分类和赛事信息；发布。
5. 新建页面，插入 WordPress“短代码”区块，填写 `[dssast_competitions limit="5"]`，发布后访问。

介绍使用 Gutenberg 原生正文，封面使用特色图片及原生媒体权限/文件类型检查；笔记投稿不提供文件上传；秀米图片接口另有严格验证。分类为独立层级分类。业务状态与 WordPress 草稿/发布状态独立，手动维护。

业务字段可留空；赛事日期为单日日期，报名时间按站点时区保存到分钟。报名开始不得晚于截止；不强制报名截止早于赛事日期，以支持现场或补报名。修改站点时区不会自动转换已保存时间。

仅拥有 `manage_options` 的管理员可维护赛事。业务字段保存校验对象权限、Nonce、自动保存和修订，拒绝数组、非法状态、无效日期及非 HTTP(S) 链接。校验失败整组业务字段保持原值，显示错误通知；标题/正文可能独立保存成功。Nonce 缺失时不修改业务字段。

停用保留全部内容和分类，移除赛事路由；重新启用可恢复。未提供卸载删除逻辑，删除插件也保留数据。启停时刷新固定链接规则。

## 范围与限制

## 笔记与新闻

在区块主题页面插入短代码 `[dssast_note_submit]`。具有 read 权限的登录用户可投稿，服务器固定保存为 pending，不能自行发布或通过后台/REST 修改笔记。页面显示本人的最近 30 条投稿。管理员在“学习笔记”审核；直接发布，或填写审核意见、勾选“退回作者修改”并更新。退回保存为 draft，作者可在投稿页面修改再提交。待审核及已发布笔记不允许作者改写。投稿标题和正文有长度限制，新投稿每分钟最多一篇；不会授予媒体上传或原生文章编辑权限。请将投稿页面从整页缓存/CDN 缓存中排除，以避免缓存登录用户信息或 Nonce。

新闻公告继续使用原生“文章”，启用插件时创建 `dssast-news`（新闻）与 `dssast-announcement`（公告）分类。原生文章权限不变。升级已有安装后停用再启用一次以创建分类和刷新路由。

秀米配置、安全策略及限制见 [XIUMI.md](XIUMI.md)。秀米同步默认关闭，配置密钥并绑定管理员账号后启用。媒体处理需要 GD 或 Imagick。停用保留笔记、媒体、绑定数据和错误记录。

未实现自定义动态区块或额外用户角色。业务字段不随核心修订恢复、不做自动保存，不开放 REST meta 接口；前端团队使用 PHP 获取。默认赛事单页由主题处理，主题不会自动展示业务字段；独立验证请使用 Shortcode。无线上操作。

已在 WordPress 7.1.4 / PHP 8.3.36 / SQLite 本地环境完成语法、集成与 HTTP 检查；详见 TESTING.md。MySQL/MariaDB、浏览器 Gutenberg 交互和真实秀米服务联调仍待验收。
