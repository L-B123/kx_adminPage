# DSSAST CMS 0.4.4

笃实书院学生科协的 WordPress 插件。后台通过“内容管理”进入赛事、笔记审核、新闻、公告和秀米同步。

- **内容管理**设有赛事信息管理、笔记信息管理和新闻公告管理三个入口。点击顶部数量可直达待审笔记或已发布赛事。新闻公告卡片提供秀米同步入口。笔记、新闻和公告管理支持搜索和分页。
- **赛事**使用经典编辑器维护介绍，并支持从列表快速编辑赛事状态、日期、报名时间及链接。学生从公开赛事页面进入管理员配置的报名表。赛事状态和 WordPress 发布状态分别维护。
- **学习笔记**由订阅者等已登录用户从前台投稿。管理员退回时填写审核意见，作者修改后重新提交。
- **秀米同步**把新稿保存为新闻草稿。运营人员可审核、调整分类，再手动发布。

## 安装

1. 准备 WordPress 6.6+ 与 PHP 7.4+。实际测试记录见[本地验收](TESTING.md)。秀米图片同步需要 GD 或 Imagick。
2. 在“插件 → 安装插件 → 上传插件”上传发布 ZIP，或将 `dssast-cms` 目录复制到 `wp-content/plugins/`。
3. 启用插件，检查“内容管理”“赛事”和“学习笔记”入口。升级使用同一个插件目录。停用保留既有内容，启用时刷新固定链接。

Windows 本地安装和登录步骤见[本地测试指导](LOCAL-TEST-GUIDE.md)。后台操作见[管理员手册](ADMIN-GUIDE.md)。栏目接入、负责人和上线验收见[前台集成与上线交接](FRONTEND-INTEGRATION.md)。秀米应用设置见[秀米同步配置](XIUMI.md)。
